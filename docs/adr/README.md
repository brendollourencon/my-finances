# ADRs (Architecture Decision Records)

Um arquivo por decisão relevante, numerado em ordem (`NNNN-titulo-em-kebab-case.md`). Decisões substituídas não são apagadas: mudam para `Substituída por NNNN`.

Modelo:

```
# NNNN. Título

- Status: proposta | aceita | substituída por NNNN
- Data: AAAA-MM-DD

## Contexto
## Decisão
## Alternativas consideradas
## Consequências
```
